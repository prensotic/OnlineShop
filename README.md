# Online shop 
Разрабатывал интернет магазин с использованием стека:
**Backend-часть:**
- Java 26
- Spring Framework 7
- Spring MVC
- Spring Security
- Hibernate 7
- Jakarta Servlet API

**Frontend-часть:**
- HTML/CSS
- Thymeleaf

**База данных:**
- PostgreSQL

**Сервер:**
- Плагин Smart Tomcat

Название бд `online_shop`
Локальный http: `http://localhost:8080`

## Функционал
В проекте были реализованы аутентификация и авторизация, разделения на роли. Для пользователя есть базовый доступ к 
магазину и просмотру товаров, для авторизованных пользователей возможность добавлять товары в корзину, оформление заказов,
просмотр профиля и установка/редактирование персональных данных. Для администраторов предусмотрено дополнительной CRUD 
приложение, для управления данными заказов, товаров и тп...

## Архитектура
Приложение использует многослойную архитектуру, которая включает в себя сущности (entities), репозитории (repositories),
сервисы (services), контроллеры (controllers) и представления (views).

## Безопасность
Для безопасности приложения используется Spring Security (Форма входа, проверка авторизации пользователя, кодирование 
паролей, ограничения доступа к URL в зависимости от роли).

## Развитие
Планируется в будущем:
- Комментарии (после покупки товара можно оставить личный отзыв)
- сделать рейтинг товаров
- Платежная система (сохранять платежи после оформления заказа, сделать баланс пользователя)
- Тестирование (unit-тесты для слоев приложения)
- Валидация данных
- DTO

## Запуск приложения
Для запуска потребуются
- установленная Java
- Maven
- PostgreSQL
- Apache Tomcat (я использовал плагин Smart Tomcat)
